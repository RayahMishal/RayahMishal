Health Informatics graduate focused on **healthcare integration and interoperability**: HL7 v2, FHIR, SQL and Python. Based in Saudi Arabia.

## Projects

| Project | What it does | Stack |
|---|---|---|
| [**fhir-gateway**](https://github.com/RayahMishal/fhir-gateway) | REST API that converts HL7 v2 admission messages to FHIR R4 Patient and Encounter, with version history, search, an audit log and consistency scoring. Unsafe messages are rejected with a FHIR OperationOutcome. | Python, Flask, SQLite, FHIR, HL7 |
| [**unihl7**](https://github.com/RayahMishal/unihl7) | One engine and a small profile per sender normalizes different HL7 v2 dialects into one canonical model, links the same patient across systems, outputs FHIR and receives messages in real time over MLLP. | Python, HL7 v2, FHIR, MLLP |
| [**hl7-message-parser**](https://github.com/RayahMishal/hl7-message-parser) | Turns raw HL7 v2 messages into readable clinical information (demographics, encounters, orders, results with critical flags) and warns about data-quality problems. Python CLI and browser version. | Python, JavaScript, HL7 v2 |
| [**rayahcare**](https://github.com/RayahMishal/rayahcare) | Clinical decision-support prototype: NEWS2 early-warning score, red-flag extraction from notes with negation handling, lab flags and an explainable summary. | JavaScript, HTML, CSS |
